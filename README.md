# 扫地机器人智能客服

基于 LangChain Agent、Chroma RAG 和 Streamlit 的本机个人学习项目。

## 功能

- PDF/TXT 知识库问答、选购咨询、维护与故障排查。
- 在线城市温湿度查询：Open-Meteo + GeoNames，支持服务收录的城市；同名地区需补充省份或国家。
- CSV 示例使用记录查询与报告生成。
- 多对话新建、切换、删除；根据首个问题自动命名。
- SQLite 保存聊天展示记录和完整 Agent 消息（包括工具调用），刷新或重启后恢复。
- 流式回答、工具耗时、模型调用及异常日志。

## 启动

在项目根目录、使用 PyCharm 成功运行项目的 Python 解释器执行：

```powershell
python -m pip install -r requirements.txt
python main.py
python -m streamlit run app.py --server.address 127.0.0.1
```

安装依赖用于新环境；已有可用环境不必重复安装。`main.py` 用于首次知识库入库及检索示例，日常启动无需重复运行。

新环境将 `.env.example` 复制为 `.env`，填入模型服务密钥和接口地址；模型名称位于 `config/rag.yaml`。对话模型和向量模型都需由配置的接口支持。

`requirements.txt` 记录实际运行环境的直接依赖版本，并不是完整的跨平台锁文件。

## 对话保存

- 路径：`config/agent.yaml` 的 `conversation_db_path`，默认 `data/conversations.sqlite3`。
- 新建对话不会清空旧对话；侧边栏圆点表示当前对话。
- 首轮成功回答后自动命名；保存失败或模型异常时不写入半截对话。
- 删除当前对话会删除数据库中的该条记录；删除最后一个后自动创建空白对话。
- 升级时仍在原 Streamlit 页面内存中的多对话会自动迁移；此前已经关闭且未保存的旧页面记录无法恢复。
- 数据库是本机单用户存储，多个浏览器窗口可看到同一本地历史；本项目没有账户系统。
- 同一对话在多个窗口同时修改时，旧版本保存会被拒绝，刷新后可继续；不会覆盖新记录或恢复已删除的对话。

## 天气来源

天气不再是北京、上海、广州三个固定示例。工具先查询城市坐标，再读取当前气温、相对湿度、数据时间和时区。

Open-Meteo 的当前条件来自天气模型估计，不代表室内传感器实测或长期气候。请求失败时会明确提示，不回退到模拟数值。

数据来源：[Open-Meteo](https://open-meteo.com/) 与 [GeoNames](https://www.geonames.org/)。当前使用面向非商业用途的公开接口；正式商业部署应按服务方条款选择方案。

## 验证

```powershell
python -m unittest discover -s tests -v
```

自动测试使用模拟模型及 HTTP 响应，不消耗模型调用额度；覆盖页面操作、历史隔离与恢复、完整工具消息序列、并发版本保护、迁移及天气异常分支。

手工检查：分别在 A、B 对话提供不同的地板信息，切换后追问；重启后再次追问；再查询杭州等此前不支持的城市。

## 当前边界

- 使用报告仍基于本地示例 CSV，不代表真实消费者记录。
- 天气查询依赖网络，地名不存在或存在歧义时需要补充信息。
- 当前知识库用 MD5 跳过重复文件；更新资料不会自动删除旧片段。
- 日志：`logs/app.log`；本机数据库、日志及密钥文件均被 Git 忽略。
